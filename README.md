# Clinical Data Dashboards – Power BI

## Overview
This repository showcases interactive dashboards built in Power BI for clinical trial data analysis.  
The projects demonstrate skills in SQL, Power BI (DAX, Power Query, Data Modeling), and clinical research documentation.

## Projects

### 1. Clinical Trial Enrollment Dashboard
- Tracks 100 patients across 4 trial sites
- Visualizes enrollment by site, patient status distribution, and adverse events by severity
- Built using DAX measures and Power Query for data cleaning

### 2. Clinical Trial Site Performance & Compliance Dashboard
- Monitors 6 trial sites on enrollment vs. target
- Displays protocol deviation categories, query resolution time, and monitoring visit compliance
- Includes a site‑level compliance scoring system to flag at‑risk sites

## Skills Demonstrated
- Power BI: Dashboard design, DAX, Power Query
- SQL: Data cleaning, joins, aggregation
- Clinical Research: ICH‑GCP, adverse event reporting, compliance tracking
- Data Visualization: Interactive dashboards for decision‑making

## How to Use
1. Download the `.pbix` files from this repository.
2. Open in **Power BI Desktop**.
3. Explore dashboards interactively (filters, slicers, drill‑downs).
